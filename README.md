# COS 201 — Computer Programming I: Week 3 Practical

Topic: Variables, Data Types, Expressions and Input/Output.

## Programs
| File | Description |
|------|-------------|
| `SimpleCalculator.java` | Reads two numbers; shows sum, difference, product, quotient and remainder. |
| `AverageCalculator.java` | Reads three scores; shows their sum and average. |
| `ItemCost.java` | Reads item name, unit price and quantity; shows subtotal, 7.5% VAT and total. |

## Requirements
Java Development Kit (JDK) 8 or later. Check with `java -version` and `javac -version`.

## How to compile and run
```
javac SimpleCalculator.java
java SimpleCalculator

javac AverageCalculator.java
java AverageCalculator

javac ItemCost.java
java ItemCost
```

## Sample run (ItemCost)
```
Enter the item name: Notebook
Enter the unit price: 500
Enter the quantity: 4
Subtotal : 2000.00
VAT (7.5%): 150.00
Total    : 2150.00
```
